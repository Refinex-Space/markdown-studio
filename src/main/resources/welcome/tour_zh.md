# Markdown Studio 导览

这是一个草稿文件，可以随意修改。你现在处在**实时预览**中：文档已经渲染好，只有光标附近会显示 Markdown 源码。

## 在文档里直接写

把光标放进**粗体**、*斜体*、~~删除线~~或 `行内代码` 里，就能看到它们的标记；移开光标，又会恢复渲染。链接也一样：[CommonMark](https://commonmark.org) 会在浏览器中打开。

选中几个字，上方会出现格式工具栏。

## 用 / 插入

在空行开头输入 `/`，选择要插入的块：标题、列表、表格、代码块、公式、提示块或图表。在下面这行试试：



## 表格

| 布局 | 看到的内容 | 适合 |
| :--- | :--- | :--- |
| 实时预览 | 可编辑的渲染文档 | 写作 |
| 源码和预览 | 源码与预览并排 | 检查 Markdown |
| 预览 | 渲染后的文档 | 阅读 |

点击单元格即可编辑，右键单元格可以增删、移动行和列。

## 提示块、任务与脚注

> [!TIP]
> 在任意位置右键，可以找到「格式 / 段落 / 插入」；所有命令也都能在 Find Action 中搜到。

- [x] 打开导览
- [ ] 在空行输入 `/`
- [ ] 在编辑器工具栏切换布局

脚注可以把补充说明放到文末。[^1]

## IDE 能力照常可用

撤销、本地历史和版本控制都能看到每一次编辑。右侧的大纲列出所有标题；上方工具栏可以在实时预览、源码、源码和预览、预览之间切换。
